      Technical details

      Duplicate songs

      Same YouTube video, or same artist and title (ignoring “Official Video”, “Lyrics”, “feat.”, “Remastered” and so on). The oldest copy is ticked as the one to keep.

      Accounts

      Connect your accounts to use your private playlists. Your logins stay on this computer.

      YouTube

      YouTube doesn't let apps log in directly, so SwimTunes uses the YouTube login of a web browser on this computer. Sign in to YouTube in that browser first. Firefox works best: on Windows, Chrome and Edge lock their logins so other apps can't use them.

      Chrome or Edge on Windows? Use a cookies.txt file instead

      In your browser, install a "cookies.txt" export extension (for example Get cookies.txt LOCALLY), open youtube.com while signed in, export the cookies, then pick the file here. Treat that file like a password.

        My folder rules

        Each rule sends matching songs to a folder. When a song matches several rules, the one with the most matching keywords wins. Keywords can be a genre (pop, rock, rap), a style (post-punk, house, synth-pop), a country (Russia, France, RU), cyrillic (songs with Russian/Cyrillic titles), or an artist name. Separate keywords with commas.
